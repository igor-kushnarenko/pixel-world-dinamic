# Atmosphere Engine 0.3.0

Самостоятельная библиотека TypeScript + Three.js + GLSL. Состояние на 05.11.2026.

## Возможности

- Процедурное небо: синий дневной градиент, ночная палитра без луны, неподвижные мерцающие звёзды (опционально), пасмурность.
- Два GPU-плана облаков с независимыми глубиной, скоростью, покрытием и плотностью, общим ветром и стабильным шумом.
- Для каждого внешнего PNG-слоя — равномерная дымка и нижний туман с клублением; управление `weather.layers[id]`: `hazeDensity`, `fogDensity`, `fogAmount`, `billowing`.
- Дождь, гроза, оконные капли с объединением и преломлением; оконная маска, глубина и перекрытие последующими слоями.
- Мерцание маяков, многополосные воздушные трассы, несколько классов машин, подробный ближний коридор.
- Городские световые маски, локальный свет комнаты, затемнение по времени суток, управляемый роллет и свет предметов с затуханием по расстоянию.
- Нативное разрешение, nearest, отключённый MSAA; исходные PNG не перезаписываются.
- Пресеты и JSON import/export, воспроизводимый seed, `randomWeatherPreset(seed, layerIds)` с согласованными сочетаниями времени, облачности и осадков.

## Подключение отдельного пакета

```sh
npm install ./pixel-world-atmosphere-engine-0.3.0.tgz
```

```ts
import {AtmosphereEngine, randomWeatherPreset} from '@pixel-world/atmosphere-engine';
const engine = await AtmosphereEngine.create({
  container: document.querySelector('#scene')!,
  scene: {width: 480, height: 270},
});
engine.setParameters(randomWeatherPreset(42, []));
engine.start();
// При удалении сцены: engine.dispose();
```

Контейнеру нужна явная высота. Для новой локации передайте собственные `layers`, `windowMask` и `lights`; координаты идут от верхнего левого угла в логических пикселях. Канонический базовый пресет сохраняет 22:00 без луны, облаков и звёзд; приложение отдельно включает звёзды для ясной ночи.

## Свет перемещаемых предметов

```ts
import {createSpriteMaterial, windowTransmission} from '@pixel-world/atmosphere-engine';
// image должна быть декодирована; размеры задаёт интегратор.
const material = createSpriteMaterial(image, 280, 260);
container.append(material.canvas);
material.update(500, 820, {
  ambient: .25, transmission: windowTransmission(.6),
  lights: [{x: 100, y: 700, radius: 620, intensity: 1.4, color: [1,.78,.51]}],
});
// update(x, bottom, state): левая координата и нижняя граница предмета.
// Экран, клавиатура и индикаторы рисуются отдельными излучающими слоями.
material.dispose();
```

Свет ослабевает по закону `1/(1+(distance/radius)^2)`, сторона в направлении источника освещена сильнее. Это мягкая аппроксимация без карты нормалей и объёмных теней. Поле света 17×17 интерполируется поверх чёткого исходного спрайта; RGB ограничивается диапазоном canvas. `minimumAmbient` по умолчанию .015. `sampleSpriteLight` позволяет вычислять свет отдельно без DOM. Закрытие окна подавляет внешний свет, но не локальные приборы.

## Роллет в другой комнате

`scene.shutter`: `top`, `bottom`, `depth`, опциональные `texture`, `left`, `right`, `texturePeriod`, `interiorLights`. По умолчанию горизонтальные границы равны ширине сцены, период — высоте предоставленной текстуры (9 для процедурных ламелей). Четыре источника в порядке полка/стена/радио/компьютер задаются `{x,y,radiusX,radiusY}`; значения по умолчанию масштабируются под разрешение. Требуется оконная маска. `setWindowShutter(closed, [shelf,wall,radio,computer])`: все уровни 0…1. Глубину задайте перед комнатой и предметами.

## Граница ответственности

Библиотека экспортируется из `src/engine/index.ts`, сборка — `lib/atmosphere-engine.js` и типы. Three.js остаётся внешней зависимостью. В пакет не входят изображения комнаты, музыка, видео, `file_system`, радио-потоки и интерфейс приложения. Перемещение предметов, коллизии подоконника, Norton Commander, плееры внутри ЭЛТ, звук, горячие клавиши и переходы панорам находятся в `src/experience`; они используют публичные методы движка. Режим заполнения экрана и допустимое обрезание выбирает хост.

Клавиша P и кнопка случайной погоды реализованы в приложении, а генератор погоды доступен библиотеке. Свои часы реальной погоды и сеть интегратор подключает самостоятельно.

## Проверка и сборка

`npm test`, `npm run build`, `node tests/random-weather-browser.mjs`. `npm pack` автоматически собирает библиотеку; `private: true` предохраняет от случайной публикации в npm registry и не мешает локальному tarball. Подробный API — в `docs/API.md`, интеграция — `docs/INTEGRATION.md`.
