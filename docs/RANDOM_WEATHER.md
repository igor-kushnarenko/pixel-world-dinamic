# Небо и случайная погода

В разделе «Сцена» находится кнопка «Случайная погода · P». Горячая клавиша P (также З на русской раскладке) выбирает новое согласованное сочетание. Она не срабатывает при вводе текста или управлении медиа.

Сценарии: чистое небо, переменная облачность, пасмурная погода, дождь, гроза, туман. Время суток, облачность, плотность двух GPU-планов, ветер и дымка/туман всех городских планов выбираются совместно. Дождь требует плотного облачного покрытия и пасмурной палитры; гроза включает молнии; туман ограничивает ветер и тяготеет к ночи/раннему утру. Ближние слои получают меньше атмосферного заполнения, чем дальние.

Дневная палитра — синий зенит и светло-голубой горизонт. Звёзды в ясную ночь имеют постоянные координаты и медленно меняющуюся яркость; днём, при дожде, грозе и сильной сплошной облачности они скрыты. Луна не добавляется. Канонический базовый API-пресет сохраняет starsEnabled=false; сцена квартиры явно включает звёзды.

API движка: `randomWeatherPreset(seed, layerIds)` возвращает `{kind, name, parameters}`. Повторение seed воспроизводит пресет. Параметр `sky.overcast` (0..1) задаёт долю пасмурной палитры; дождь дополнительно гарантирует её включение. Полный набор настроек можно сохранить как обычный пресет. В квартире сохраняются время, seed, плотность облаков и параметры каждого атмосферного плана.

Проверки: `npm test`; `node tests/random-weather-browser.mjs` — изолированные GPU-кадры и UI. Последняя проверка: 30 звёзд меняют яркость, 0 звёзд меняют координаты, 0 звёзд видны в дневном кадре; RGB зенита [20,88,180], горизонта [132,200,241]. SwiftShader используется для корректности, не для измерения целевого FPS.
