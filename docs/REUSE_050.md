# Atmosphere Engine 0.5.0 — основа новых панорам

## Что поставляется

1. `pixel-world-atmosphere-engine-0.5.0.tgz` — устанавливаемая библиотека, исходники, TypeScript types, маленький пример и полный пример квартиры в `kits/apartment.zip`. Одного tgz достаточно для передачи всех наработок в новый чат.
2. `pixel-world-panorama-starter-0.5.0.zip` — готовый минимальный проект, уже содержит этот tgz. `npm install`, `npm run dev`; замените `location.ts` собственными слоями.
3. `pixel-world-apartment-starter-0.5.0.zip` — полный проект квартиры с интерфейсом и взаимодействиями. `npm install`, `npm run dev`. Содержит графику примера, исходники и инструменты, без пользовательского медиа. Наполните `file_system/PHOTO`, `MUSIC`, `VIDEO`, `TEXT` своими файлами. Каталог собирается автоматически. Это удобная основа для другой комнаты.

## Минимальное использование

```ts
import {PanoramaExperience} from '@pixel-world/atmosphere-engine';
const panorama = await PanoramaExperience.create({
 container: document.querySelector('#scene')!,
 scene: {width: 1672, height: 941, layers: [
   {id:'far',source:'/assets/far.png',depth:20,scope:'world'},
   {id:'near',source:'/assets/near.png',depth:60,scope:'world'},
 ]},
 soundscape:'city', storageKey:'my-new-panorama.v1',
 transitionSeconds:5, fillScreen:true,
});
// Плавное изменение:
panorama.setWeather({weather:{rain:.7}});
// Немедленное изменение при необходимости:
panorama.setWeather({weather:{rain:0}},0);
// При удалении страницы/сцены:
panorama.dispose();
```

Задайте контейнеру высоту. `PanoramaExperience` владеет RAF: не вызывайте `engine.start()` параллельно. Через `panorama.engine` доступны все низкоуровневые методы, маски, свет и тени. `onFrame(engine,dt)` позволяет подключить местное взаимодействие. Независимый `WeatherTransition` подходит для собственного цикла игры.

## Перенесённые возможности

- Чёткий нативный рендер, pixel-art, целое масштабирование; опциональное заполнение экрана с обрезкой.
- Ночное небо без луны; синий дневной градиент, закат, рассвет, мерцающие звёзды, пасмурность.
- Два GPU-плана облаков, стабильный шум, ветер, плотность, покрытие, независимые высота и глубина.
- Дымка и нижний клубящийся туман для каждого внешнего слоя.
- Дождь и грозы, молнии, размытие дальних изображений. Масштаб эффекта размытия сейчас зависит от порядка глубины 0…80; используйте рекомендованные значения 20/40/60/80.
- Оконные стекающие капли, слияние, преломление, извилистые потёки; 10 секунд высыхания после нулевого дождя. Мелкие статичные капли исключены по последней правке пользователя. При отсутствии windowMask эффект стекла отключён.
- Пресеты, экспорт/импорт JSON, согласованная случайная погода; плавные переходы по умолчанию за 5 секунд. Seed сохраняется во время перехода, чтобы не менять рисунок шума и не сбрасывать воду.
- Компактное меню, ползунки погоды, индивидуальные настройки атмосферы слоёв, звук, громкость, роллет при наличии, полный экран. Настройки сохраняются при заданном уникальном storageKey.
- P/З — случайная погода; ←/→ — виды; M/Ь — звук; F/А — полный экран; Esc — закрыть меню. Поля ввода не перехватываются. Для нескольких независимых сцен отключайте глобальные клавиши `hotkeys:false` у фоновых экземпляров.
- Настраиваемые виды: `views:[{name,layers:{far:{x,y,scale}}}]`; плавное смещение и масштабирование слоёв за 2 секунды.
- Городские маяки, дальние и ближние воздушные трассы, разные формы транспорта.
- Маски огней, локальный свет, материалы перемещаемых предметов, их затухание по расстоянию, управляемый роллет и фильтрация внешних звуков.
- Тени из предоставленного 0.4.0: до четырёх источников и четырёх отбрасывающих слоёв, точечный и направленный свет, маски получения и отбрасывания.
- Публичный `SillPhysics`: масса, инерция, трение, столкновения, сон, глубина подоконника, настраиваемая геометрия. Радио и компьютер из полного примера уже используют его.
- В полном примере: радио со станциями, компьютер с подсветкой клавиатуры и ЭЛТ, часы/погода, файловый менеджер, фото, музыка и видео внутри дисплея, циклическое воспроизведение. Управление виртуальным компьютером мышью, физическая клавиатура остаётся у панорамы.

## Звук конкретного пейзажа

`soundscape:'city'|'forest'|'coast'|'quiet'`. City использует процедурные городской гул, пролёты и редкие сирены. Forest даёт тихий ветровой фон, coast — более плотный шум; это синтезированные основы, не записи птиц/моря. Во всех профилях интенсивность шумового дождя следует осадкам. Подключите характерные записи через `sounds:[{url:'/audio/birds.ogg',volume:.4,loop:true}]`. Можно использовать quiet и только свои записи. Файлы должны разрешать CORS, если находятся на другом домене. Звук запускается только после нажатия кнопки или клавиши пользователем; на новом открытии сам не включается.

## Окно, свет и предметы

`windowMask` — полноразмерная маска, белым проём. Все внешние эффекты ограничены ей. Роллет задаётся `scene.shutter` и располагается перед внешними слоями, но за комнатой/предметами. Положения светильников задаются данными локации. В оболочке можно управлять дополнительными приборами через onFrame и API двигателя; полный пример содержит готовые кнопки света, радио, компьютера и роллета.

Архитектура другой комнаты требует своих зон клика, масок света и геометрии подоконника. Сами механизмы уже реализованы, а их данные следует подогнать к новой графике. Физика — вертикальные 2.5D спрайты, без вращения и трёхмерных стопок. Тени — проекции по явно заданным плоскостям; исходные PNG не превращаются автоматически в объёмные модели.

## Обновление с 0.4.0

Существующий `AtmosphereEngine` и API теней сохранены. Новая оболочка опциональна. Пакет содержит src/engine для продолжения разработки в новом чате. Приложите tgz и опишите новую локацию; для готового запуска используйте один из starter ZIP. Исходный предоставленный 0.4.0 не перезаписывается.
