# Файлы компьютера

Корень компьютера C:/ соответствует папке `file_system` в корне проекта. Сейчас созданы PHOTO, VIDEO, MUSIC и TEXT. Можно создавать любые свои вложенные папки и добавлять файлы с русскими именами, пробелами и любыми расширениями.

↑/↓ — выделение; ←/→ — предыдущая/следующая страница списка; Enter — открыть папку; Esc или строка `..` — на уровень выше. Esc из корня возвращает часы и погоду. Стрелки внутри файлового менеджера не переключают панораму. Те же клавиши можно нажимать на модели компьютера.

Файлы отображаются с размером. Enter открывает поддерживаемый файл:

- Фотографии PNG, JPG/JPEG, WebP, GIF, AVIF, BMP, SVG: просмотр на всю страницу с сохранением пропорций. ←/→ или ↑/↓ — соседняя фотография в той же папке, Esc — закрыть. Есть экранные кнопки и отдельный переход в полноэкранный режим браузера.
- Музыка MP3, WAV, OGG/Opus, M4A/AAC, FLAC: плеер с паузой, остановкой, предыдущей/следующей композицией, перемоткой, временем и громкостью. Громкость сохраняется локально. После окончания запускается следующая композиция этой папки; после последней воспроизведение останавливается.
- Видео MP4, WebM, OGV, MOV, M4V: окно на всю страницу с обычными элементами видеоплеера и кнопкой полноэкранного режима. Esc закрывает просмотр.

Фактическая поддержка звука и видео зависит от кодека браузера; неподдерживаемый файл показывает сообщение. Если автозапуск заблокирован, нажмите воспроизведение. При закрытии медиа останавливается, выделение и текущая папка сохраняются. Стрелки и Esc во время просмотра не управляют сценой или файловым браузером. Просмотр текстовых файлов пока не реализован.

Браузерный сценарий проверки на имеющихся тестовых медиа: `node tests/media-browser.mjs` при запущенном dev-сервере на порту 5182.

В режиме разработки изменения дерева автоматически обновляют страницу. Для GitHub Pages новые файлы должны быть сохранены в Git, собраны и опубликованы: сайт показывает опубликованную копию папки, а не живой доступ к диску компьютера. Все опубликованные файлы доступны посетителям сайта.

Сборка автоматически создаёт `dist/assets/file-system-index.json` и копирует содержимое в `dist/file_system`. Ничего вручную перечислять в коде не нужно. Символические ссылки не включаются. Пустые папки хранятся в Git с `.gitkeep`; эти служебные маркеры в списке не показываются. Инструкция к папке находится здесь, чтобы не загромождать корень компьютера.
