# Файлы компьютера

Корень компьютера C:/ соответствует папке `file_system` в корне проекта. Сейчас созданы PHOTO, VIDEO, MUSIC и TEXT. Можно создавать любые свои вложенные папки и добавлять файлы с русскими именами, пробелами и любыми расширениями.

↑/↓ — выделение; ←/→ — предыдущая/следующая страница списка; Enter — открыть папку; Esc или строка `..` — на уровень выше. Esc из корня возвращает часы и погоду. Стрелки внутри файлового менеджера не переключают панораму. Те же клавиши можно нажимать на модели компьютера.

Файлы отображаются с размером. Их просмотр и воспроизведение пока не реализованы: Enter на файле показывает соответствующее сообщение.

В режиме разработки изменения дерева автоматически обновляют страницу. Для GitHub Pages новые файлы должны быть сохранены в Git, собраны и опубликованы: сайт показывает опубликованную копию папки, а не живой доступ к диску компьютера. Все опубликованные файлы доступны посетителям сайта.

Сборка автоматически создаёт `dist/assets/file-system-index.json` и копирует содержимое в `dist/file_system`. Ничего вручную перечислять в коде не нужно. Символические ссылки не включаются. Пустые папки хранятся в Git с `.gitkeep`; эти служебные маркеры в списке не показываются. Инструкция к папке находится здесь, чтобы не загромождать корень компьютера.
