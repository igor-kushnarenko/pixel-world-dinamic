# Быстрый старт 0.5.0
Положите pixel-world-atmosphere-engine-0.5.0.tgz рядом с package.json. Выполните npm install, затем npm run dev. Сборка: npm run build.
location.ts содержит независимые демонстрационные слои, создаваемые canvas. Замените их своими PNG, сохраните фактический размер холста и порядок глубин. Для сцены без окна уберите windowMask и слой room-0a; оконные капли автоматически отключатся.
P — плавная случайная погода, стрелки — виды, M — звук, F — полный экран, Esc — меню. Приборы управляются мышью в полном примере квартиры.
